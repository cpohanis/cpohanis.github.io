# Privacy policy

rclone-backup is a private backup tool used only by its owner.

## What it accesses

It uses Google's "drive.file" permission. That means it can only see and change the files it has created itself in the owner's Google Drive. It cannot read any other file in that Drive.

## What it does with data

It uploads backup copies of the owner's own files to the owner's own Google Drive, and nothing else. No data is collected, sold, shared with anyone, or used for advertising. There are no cookies, no tracking and no analytics.

## Who uses it

Only the owner. Nobody else's data is ever handled.
